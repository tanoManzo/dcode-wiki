The editor comes next.

This page is the future password-protected editing area. Once the lab approves the public design, it will provide simple forms for meetings, papers, members, and resource pages—no GitHub knowledge required.

Why is editing not active yet?A password cannot be stored securely inside a public GitHub Pages site. The production editor will connect to a free Cloudflare function, where the password and GitHub credentials remain private.

The visual prototype contains no password or secret token, so it is safe to publish and share for review.
